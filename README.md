# 오늘, 카를로 아쿠티스와 함께 걷습니다

2027 서울 세계청년대회(WYD)를 준비하며, 본당을 찾아오는 **성 카를로 아쿠티스**의 삶을
청소년·청년과 함께 묵상하기 위해 만든 **모바일 2D 힐링 워킹 게임**입니다.

> “항상 예수님과 함께 있는 것, 이것이 나의 인생 계획입니다.”

이 저장소에는 전체 8일 여정 가운데 **DAY 1(금요일) 수직 슬라이스**가 들어 있습니다.
설치 없이 스마트폰 브라우저에서 바로 열어 약 10~15분간 플레이할 수 있습니다.

플레이어의 선택은 평가되지 않습니다.

## 플레이 방법

- **걷기** — 화면 아래쪽 아무 곳이나 누른 채 손가락을 움직이면 그 자리에 조이스틱이 생깁니다.
- **살펴보기 / 말 걸기** — 대상에 가까이 가면 오른쪽 아래에 둥근 버튼이 나타납니다.
- **대화 넘기기** — 화면을 가볍게 누릅니다. (한 번 더 누르면 문장이 즉시 완성됩니다.)
- **저장** — 자동 저장됩니다. 브라우저의 localStorage에만 기록되며 서버로 전송되지 않습니다.
- 세로 화면 전용입니다. 가로로 돌리면 안내가 표시됩니다.

## 로컬에서 실행하기

`file://` 로 열면 일부 브라우저에서 제한이 있으므로 간단한 정적 서버를 사용하세요.

```bash
node tools/dev-server.js
```

그리고 브라우저에서 `http://localhost:5173` 을 엽니다.
파이썬이 있다면 `python -m http.server 5173` 도 됩니다.

## 수집과 사진첩

**말씀 카드 20장** — 성 카를로 아쿠티스의 말, 성경 말씀, 성인 성녀의 말씀을
걷고 만나고 물어보는 동안 하나씩 얻습니다. 아직 얻지 못한 카드에는
어디에서 만날 수 있는지만 살짝 적혀 있습니다.

**사진첩** — 프레임을 끌어 옮기고 크기를 바꾼 뒤 찍습니다.
사진은 게임 안 사진첩에 담기고(최대 12장), 휴대폰에도 저장할 수 있습니다.
사진 아래에는 게임 제목과 찍은 시각이 작게 남습니다.

둘 다 제목 화면과 일시정지 화면의 **보관함**에서 볼 수 있습니다.
모든 기록은 기기 안에만 저장되며 어디로도 전송되지 않습니다.

## 기술

HTML5 · CSS3 · JavaScript ES6+ · Phaser 3 · Web Audio API · localStorage.
빌드 과정이 없습니다. npm 설치도, 서버도, 로그인도, 데이터베이스도 필요 없습니다.

- 기준 해상도 **390 × 844**, `Phaser.Scale.FIT` 으로 화면이 잘리지 않게 축소합니다.
- 본문 18px, 대화 21px, 터치 버튼 최소 56px, 버튼 간격 14px 이상.
- 60FPS 목표. 저사양 기기를 위해 `powerPreference: 'low-power'`, 최소 30FPS 보정.

## 그림과 소리

**외부 이미지·음원 파일을 전혀 사용하지 않습니다.**
모든 그림은 `js/systems/TextureFactory.js` 에서 단순한 도형으로 직접 그려 만들고,
파도 소리·방의 공기·화음·효과음은 `js/systems/AudioSystem.js` 에서
Web Audio API로 실시간 합성합니다. 기존 게임이나 애니메이션의 캐릭터를 모방하지 않았습니다.

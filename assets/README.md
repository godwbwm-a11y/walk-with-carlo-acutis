# assets

게임 안에서 쓰는 그림과 소리는 여기에 없습니다. 모두 코드로 직접 만들어집니다.

- 그림 — `js/systems/TextureFactory.js` 와 `TextureDay2/3/5/6/7.js` 에서
  단순한 도형으로 그려 텍스처를 생성합니다.
- 소리 — `js/systems/AudioSystem.js` 에서 Web Audio API 로 실시간 합성합니다.

덕분에 외부 이미지·음원 파일이 없어 저작권 문제가 없고, 내려받는 용량도 작습니다.

## og-image.png

여기에 있는 단 하나의 파일입니다. 카카오톡·페이스북 등에 링크를 붙였을 때
보이는 **미리보기 썸네일**(1200 × 630)이며, 링크 미리보기는 정적 이미지 파일을
요구하기 때문에 예외적으로 파일로 저장해 두었습니다.

이 그림도 따로 그린 것이 아니라, 게임 안의 제목 화면과 같은 색·같은 인물 그림으로
캔버스에 직접 그려서 내보낸 것입니다. 문구나 색을 바꾸고 싶으면 같은 방식으로
다시 그려 이 파일을 덮어쓰면 됩니다.

바꾼 뒤에는 카카오톡이 이전 그림을 기억하고 있으므로
[카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing) 에서
주소를 넣고 **초기화**를 눌러야 새 그림이 보입니다.
